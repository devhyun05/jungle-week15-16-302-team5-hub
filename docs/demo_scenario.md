# 데모 시나리오

## 목표

말랑 연구소가 기본 게시판에 RAG, MCP 상품 검색, AI Agent를 연결한 슬라임 제작 지원 서비스라는 점을 보여준다.

## 시연 흐름

1. 회원가입
2. 로그인
3. 게시판 메인(`/` 또는 `/posts`)에서 검색, 카테고리, 인기 태그 필터 확인
4. 레시피 공유, 실패 질문, 후기, 일반 중 하나로 게시글 작성
5. 글쓰기에서 추천 태그를 선택하거나 직접 태그를 추가하고, 선택한 태그를 삭제해 본다
6. 게시판 메인에서 여러 태그를 동시에 선택해 좁혀 보기
7. 게시글 상세 조회
8. 댓글 작성
9. Agent 화면 이동
10. 슬라임 제작법과 구매처를 함께 묻는 요청 입력
11. RAG 내부 게시글 근거 확인
12. MCP 상품 검색 결과 확인
13. Agent 답변과 추천 태그 확인

## 데모 입력

```plain text
딸기향 투명 슬라임 만드는 법이랑 액티베이터 구매처 알려줘
```

## 기대 출력

- 선택 경로: `RAG + MCP`
- RAG 근거: 투명 슬라임 제작 순서, 액티베이터 비율, 끈적임 해결 사례
- MCP 추론 재료: 클리어 PVA 글루, 슬라임 액티베이터, 딸기향 향료, 글리터
- 상품 정보: 재료별 검색 키워드, 예상 가격대, 네이버 쇼핑 검색 링크
- Agent 답변: 내부 게시글 기준 제작 순서와 MCP 기준 구매 후보를 함께 안내
- 추천 태그: `AI도움`, `클리어슬라임`, `재료구매`, `상품검색`

## 발표 포인트

- 게시글과 댓글은 RAG 검색의 지식 데이터로 활용된다.
- 게시판은 홈과 목록을 분리하지 않고, 첫 화면에서 바로 검색과 필터를 제공한다.
- 태그 필터는 여러 개를 동시에 선택할 수 있고, 선택한 태그를 모두 포함한 게시글만 보여준다.
- 사용자는 글쓰기에서 직접 태그를 추가할 수 있다.
- MCP는 DB에 저장하지 않고, 요청 시 외부 도구 결과를 즉시 받아 화면에 보여준다.
- Agent는 사용자의 문장을 보고 RAG/MCP 중 필요한 도구를 선택한다.
- DB는 게시판 데이터와 RAG 임베딩만 저장하도록 축소했다.
