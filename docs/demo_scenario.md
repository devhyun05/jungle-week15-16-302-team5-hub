# 데모 시나리오

## 목표

말랑 연구소가 기본 게시판에 RAG, MCP 상품 검색, AI Agent를 연결한 슬라임 제작 지원 서비스라는 점을 보여준다.

## 시연 흐름

1. 회원가입
2. 로그인
3. 레시피 또는 실패 해결 게시글 작성
4. 게시글 목록에서 검색/태그/페이징 확인
5. 게시글 상세 조회
6. 댓글 작성
7. Agent 화면 이동
8. 슬라임 제작법과 구매처를 함께 묻는 요청 입력
9. RAG 내부 게시글 근거 확인
10. MCP 상품 검색 결과 확인
11. Agent 답변과 추천 태그 확인

## 데모 입력

```plain text
딸기향 투명 슬라임 만드는 법이랑 액티베이터 구매처 알려줘
```

## 기대 출력

- 선택 경로: `RAG + MCP`
- RAG 근거: 투명 슬라임 제작 순서, 액티베이터 비율, 끈적임 해결 사례
- MCP 추론 재료: 클리어 PVA 글루, 슬라임 액티베이터, 딸기향 향료, 글리터
- 상품 정보: 재료별 검색 키워드, 예상 가격대, 네이버 쇼핑 검색 링크
- Agent 답변: 내부 게시글 기준 제작 순서와 MCP 기준 구매 후보를 함께 안내
- 추천 태그: `AI도움`, `클리어슬라임`, `재료구매`, `상품검색`

## 발표 포인트

- 게시글과 댓글은 RAG 검색의 지식 데이터로 활용된다.
- MCP는 DB에 저장하지 않고, 요청 시 외부 도구 결과를 즉시 받아 화면에 보여준다.
- Agent는 사용자의 문장을 보고 RAG/MCP 중 필요한 도구를 선택한다.
- DB는 게시판 데이터와 RAG 임베딩만 저장하도록 축소했다.
