# 데모 시나리오

## 목표

말랑 연구소가 단순 게시판이 아니라 슬라임 실패 해결 AI 커뮤니티라는 점을 보여준다.

## 시연 흐름

1. 회원가입
2. 로그인
3. 실패 해결 게시글 작성
4. 게시글 상세 조회
5. 댓글 작성
6. 태그/검색/페이징 확인
7. AI 진단 요청
8. RAG 유사 사례 확인
9. MCP 습도 정보 확인
10. Agent 해결 순서 확인

## 데모 입력

```plain text
클리어 슬라임을 만들었는데 너무 끈적이고 손에 계속 묻어요.
물풀 100ml에 액티베이터를 조금 넣었고, 10분 정도 치댔어요.
```

## 기대 출력

- 상황 요약: 클리어 슬라임이 충분히 뭉치지 않고 손에 묻는 상태
- 원인 후보: 액티베이터 부족, 수분 비율 과다, 높은 습도 영향
- 비슷한 사례: 클리어 슬라임 끈적임 해결 사례 3개
- 해결 순서: 액티베이터 소량 추가, 충분히 치대기, 밀폐 후 휴지
- 추천 태그: 클리어슬라임, 끈적임, 액티베이터부족, 실패해결
