## 새로 배운 개념 메모

- 학습 코치 모드에서는 완성 코드보다 개념, 빈칸 드릴, 검토가 우선이다.
- 프로젝트 구현 완료 여부는 문서나 파일 존재만으로 판단하지 않고 실제 동작과 테스트로 판단한다.
- 0~12단계 이름은 유지하되 실제 진행 표시는 Day 0~5와 A/B/C 블록으로 맞추는 편이 덜 헷갈린다.
- 일정표의 자세한 학습 설명을 md에 전부 복사하지 않는다. md에는 agent가 놓치면 안 되는 산출물, 확인 기준, 참조 위치를 남긴다.
- 구체 항목 정합성은 `GLOWBOARD_학습_단계별_가이드.md`의 "일정표 항목 정합성 표"를 기준으로 확인한다.
- 후보 항목은 별도 파일로 남기지 않고, 일정표에서는 할 일 성격의 세부 확인 항목으로 보고 각 Day 작업 순서에서 확인한다.
