# Frontend

React, TypeScript, Vite, Tailwind CSS로 말랑 연구소 사용자 화면을 구현한다.

## 화면

- 게시판 메인: `/`와 `/posts`가 같은 화면이며, 배너, 검색, 카테고리 탭, 인기 태그 필터, 게시글 피드를 보여준다.
- 게시글 상세: 본문, 태그, 댓글, 작성자 액션, Agent 진입
- 게시글 작성 / 수정: 카테고리 선택, 태그 직접 추가, 선택 태그 삭제
- 로그인 / 회원가입
- Agent: RAG 내부 검색 결과와 MCP 상품 검색 결과를 한 화면에 표시

## 주요 기능

- FastAPI API 호출
- JWT 토큰 저장 및 인증 헤더 연결
- 카테고리별 게시글 작성 폼
- 반복 query string 기반 다중 태그 필터
- 인기 태그 최대 8개 표시
- 글쓰기 태그 직접 추가와 선택 태그 삭제
- 검색 / 페이징
- Agent 요청, route 표시, RAG 근거, 상품 검색 결과, 추천 태그 표시

## 현재 라우트

| 경로 | 화면 |
| --- | --- |
| `/` | 게시판 메인 |
| `/login` | 로그인 |
| `/signup` | 회원가입 |
| `/posts` | 게시판 메인 |
| `/posts/new` | 게시글 작성 |
| `/posts/:postId` | 게시글 상세 |
| `/posts/:postId/edit` | 게시글 수정 |
| `/agent` | Agent 실행 |

백엔드 연결 실패 시 Agent 화면은 프론트 데모 결과를 표시해 시연 흐름을 유지한다.
