# Troubleshooting

프로젝트 진행 중 발생한 문제와 해결 방법을 영역별로 정리한다.

## 목록

| 영역           | 문서                                  |
| -------------- | ------------------------------------- |
| Frontend       | [frontend](./frontend/README.md)      |
| Backend        | [backend](./backend/README.md)        |
| Database       | [database.md](./database.md)          |
| AI / RAG / MCP | [ai.md](./ai.md)                      |

## 작성 규칙

- 하나의 문제는 하나의 문서로 분리한다.
- 문서 제목은 문제 상황을 바로 알 수 있게 작성한다.
- 이미지는 `assets/{영역}/{문제명}/` 폴더에 보관한다.
- 문서에는 문제, 증상, 원인, 해결 방법, 참고 문서를 순서대로 기록한다.
